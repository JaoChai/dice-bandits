# Dice Bandits M4b Audio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add 12 synthesised 8-bit SFX, two CC0 music loops (board, battle), a HUD mute button and a title-screen sound dialog, without changing any rule and without any risk of freezing the game.

**Architecture:** A standalone client module `apps/client/src/audio/` on the Web Audio API. Pure mapping (`events.ts`) and persistence (`settings.ts`) are unit-tested in isolation; the runtime (`context.ts`, `sfx.ts`, `music.ts`) takes an injected `AudioContext` factory so it is tested with a fake. `main.ts` calls `onGameEvents(events, nextState)` fire-and-forget from both `onEvents` handlers. SFX WAV files are generated by a deterministic TypeScript synthesiser in a new `tools/sfx` workspace; music files are encoded once by the controller and committed.

**Tech Stack:** TypeScript, Web Audio API, Vite, Vitest 5 + happy-dom, Playwright 1.63, tsx (generator), ffmpeg (controller only, never in CI).

**Spec:** `docs/superpowers/specs/2026-09-30-dice-bandits-m4b-audio-design.md`

## Global Constraints

- `packages/*`, `apps/client/worker`, `tests/worker` and the protocol are NOT modified: `git diff origin/main -- packages apps/client/worker tests/worker` must stay empty.
- Every existing `data-testid` keeps its name and meaning. Existing unit + E2E tests pass unchanged (additions only).
- Every new visible string exists in `apps/client/src/i18n/en.json` and `th.json` (key parity test already exists).
- **Fire-and-forget:** exported audio functions return `void`; no game code awaits audio. All internal promises are caught.
- Failures log `console.warn('[audio] …')` at most once per file; never `console.error`, never an unhandled rejection.
- Budgets: `public/audio/sfx` ≤ 300 000 bytes; each music file ≤ 1 500 000 bytes; `public/audio` total ≤ 4 000 000 bytes.
- Test hook `window.__audioLog` exists only when `import.meta.env.VITE_TEST_HOOKS === '1'`; the production build contains no `__audioLog` and no `__db`.
- Listeners on re-rendered DOM are bound once (PR #11 lesson: double `keydown` toggled twice).
- Never run two Playwright runs at the same time on this machine (shared `test-results` → ENOENT trace failures).
- Full gate for every task: `npm run typecheck && npm run lint && npm run format:check && npm test && npm run test:worker && npm run sim -- --games 200 --players 4 && npm run sim:room -- --games 200 && npm run build && npm run e2e`.

```ts
// settings.ts
export interface AudioSettings { muted: boolean; music: number; sfx: number } // volumes 0..1
export const AUDIO_SETTINGS_KEY = 'diceBandits.audio';
export const DEFAULT_AUDIO_SETTINGS: Readonly<AudioSettings>; // { muted: false, music: 0.5, sfx: 0.8 }
export function loadAudioSettings(storage?: Pick<Storage, 'getItem'> | null): AudioSettings;
export function saveAudioSettings(settings: AudioSettings, storage?: Pick<Storage, 'setItem'> | null): void;
// events.ts
export const SFX_IDS: readonly ['click','dice','step','battleStart','hit','ko','coin','stolen','levelUp','item','town','win'];
export type SfxId = (typeof SFX_IDS)[number];
export type MusicId = 'board' | 'battle';
export const EVENT_SFX: Readonly<Record<string, Exclude<SfxId, 'click'>>>;
export function sfxForEvents(events: readonly GameEvent[]): SfxId[];
export function musicForState(state: Pick<GameState, 'phase'>): MusicId;
```
`EVENT_SFX` = `DiceRolled→dice, Moved→step, BattleStarted→battleStart, DamageDealt→hit, PlayerKO→ko, GoldGained→coin, BountyClaimed→coin, GoldStolen→stolen, LevelUp→levelUp, ItemBought→item, ItemUsed→item, TownClaimed→town, TownFlipped→town, GameEnded→win`. `sfxForEvents` keeps first-appearance order and dedupes. `musicForState` → `'battle'` iff `phase.kind === 'battle'`. `loadAudioSettings` defaults `storage` to `globalThis.localStorage` inside a try/catch; invalid JSON, a throwing storage, missing fields or out-of-range/NaN volumes fall back per field to defaults (volumes clamped to 0..1). `saveAudioSettings` swallows storage errors.

### Task 2: SFX synthesiser, 12 WAV files, audio budget — Worker, Wave 1

**Files:** Create `tools/sfx/package.json`, `tools/sfx/wav.ts`, `tools/sfx/synth.ts`, `tools/sfx/table.ts`, `tools/sfx/generate.ts`, `tools/sfx/synth.test.ts`, `scripts/check-audio-budget.mjs`, `apps/client/public/audio/sfx/*.wav`; Modify `apps/client/package.json` (test script), `package-lock.json` (via `npm install`).

**Interfaces — Produces:**
```ts
// wav.ts
export function encodeWav(samples: Int16Array, sampleRate: number): Uint8Array; // RIFF PCM 16-bit mono
// synth.ts
export type Wave = 'square' | 'triangle' | 'saw' | 'noise';
export interface Segment { wave: Wave; f0: number; f1: number; ms: number; gain?: number; duty?: number }
export interface SfxSpec { segments: Segment[]; volume: number; attackMs?: number; releaseMs?: number }
export function synth(spec: SfxSpec, sampleRate?: number): Int16Array; // default 22050; noise = seeded LCG, no Math.random
// table.ts
export const SFX_TABLE: Record<'click'|'dice'|'step'|'battleStart'|'hit'|'ko'|'coin'|'stolen'|'levelUp'|'item'|'town'|'win', SfxSpec>;
// generate.ts — writes apps/client/public/audio/sfx/<id>.wav for every table entry, prints id + bytes
```
`tools/sfx/package.json` mirrors `tools/pixelize`: `"name": "@dice-bandits/sfx"`, `"type": "module"`, scripts `test: vitest run`, `typecheck: tsc --noEmit --target ES2023 --module ESNext --moduleResolution Bundler --strict --skipLibCheck *.ts`, `generate: tsx generate.ts`; devDependencies `tsx 4.23.15`, `vitest 5.0.2`.

Sound design guide (tune by ear later, keep durations): `click` 30 ms square 1800→1600 Hz; `dice` 3×50 ms noise bursts with 40 ms gaps; `step` 60 ms triangle 440→520; `battleStart` 3 rising square notes 330/440/660 × 90 ms; `hit` 120 ms noise + square 180→60; `ko` 450 ms square 440→55; `coin` 2 notes 988/1319 × 70/180 ms square duty 0.25; `stolen` 3 falling notes 660/494/330 × 90 ms; `levelUp` arpeggio 523/659/784/1047 × 80 ms; `item` 90 ms triangle 600→900; `town` 2 bells 784/1175 × 200 ms triangle with decay; `win` fanfare 523/659/784/1047 (last 400 ms), ≤ 1.2 s. Every sound except `win` ≤ 0.6 s; attack ≥ 2 ms and release ≥ 10 ms (no clicks at edges); peak ≤ 0.8 of full scale.

`scripts/check-audio-budget.mjs` (same shape as `check-sprite-budget.mjs`): fails when `public/audio/sfx/*.wav` total > 300 000, any `public/audio/music/*` file > 1 500 000, or all of `public/audio/**` > 4 000 000; prints each total. Missing `music/` directory counts as 0 (Task 3 lands in parallel).

**Interfaces — Consumes:** Task 1. **Produces:**
```ts
// context.ts
export interface AudioGraph { ctx: AudioContext; master: GainNode; music: GainNode; sfx: GainNode }
export function createGraph(make: () => AudioContext): AudioGraph; // master→destination, music/sfx→master
export function applySettings(graph: AudioGraph, s: AudioSettings): void; // master = muted ? 0 : 1; music/sfx = volumes
export async function loadBuffer(ctx: AudioContext, url: string, fetcher?: typeof fetch): Promise<AudioBuffer | null>; // null + one console.warn on failure
// sfx.ts
export class SfxPlayer {
  constructor(graph: AudioGraph, opts: { url: (id: SfxId) => string; now: () => number; onStart?: (id: SfxId) => void; fetcher?: typeof fetch });
  preload(): void;          // starts loading all 12 buffers, never rejects
  play(id: SfxId): void;    // no-op if buffer missing, same id < 80 ms ago, or 6 voices active
}
// music.ts
export class MusicPlayer {
  constructor(graph: AudioGraph, opts: { url: (id: MusicId) => string; fetcher?: typeof fetch });
  set(track: MusicId | 'none'): void; // lazy-loads the track; 500 ms linear cross-fade; looping AudioBufferSourceNode
}
// index.ts — the only module the rest of the client imports
export function initAudio(deps?: { makeContext?: () => AudioContext | null; fetcher?: typeof fetch; now?: () => number; storage?: Storage | null }): void; // idempotent
export function onGameEvents(events: readonly GameEvent[], state: Pick<GameState, 'phase'>): void;
export function playSfx(id: SfxId): void;
export function setMusic(track: MusicId | 'none'): void;
export function getAudioSettings(): AudioSettings;
export function setAudioSettings(patch: Partial<AudioSettings>): AudioSettings; // saves + applies, returns the result
export function resetAudioForTests(): void;
```
Behaviour: `initAudio` loads settings, registers one-shot `pointerdown`/`keydown` listeners on `window` (capture) that create the context on first gesture (`makeContext` default: `window.AudioContext ?? webkitAudioContext`, `null` if absent), `resume()` it, `preload()` SFX, and start the desired music. Before unlock, `setMusic` only records the desired track and `playSfx` does nothing. `document.visibilitychange` → `ctx.suspend()` when hidden, `ctx.resume()` when visible. One delegated `click` listener on `document` plays `click` when `event.target.closest('button:not(:disabled)')`. URLs: SFX `/audio/sfx/<id>.wav`; music `/audio/music/<id>.ogg` when `new Audio().canPlayType('audio/ogg; codecs="vorbis"')` is non-empty, else `.mp3`. With `VITE_TEST_HOOKS === '1'`, `onStart` pushes the id to `window.__audioLog` (declare it in a `declare global` block). Every exported function wraps its body in `try/catch` and returns `undefined`.
